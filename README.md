# Sambridha Nepal Energy

React and Vite website for Sambridha Nepal Energy.

## Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The app includes the home, about, team, contact, solar street light, flood light and home appliance pages. The legacy `/home-applicance` URL remains available as an alias for `/home-appliance`.
